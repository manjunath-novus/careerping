# CareerPing

**Never Miss Your Chance.**

CareerPing is a simple career guidance website that helps students discover competitive exams, job opportunities, and higher-study options.

## Features

- Browse opportunities for PUC and degree students.
- Filter opportunities by education level and category.
- Check age-based eligibility.
- View exam dates, deadlines, and application links.
- Get basic reminders for upcoming deadlines.

## Technologies Used

- HTML
- CSS
- JavaScript
- JSON
